# JU-6 Pi stickers

Print `JU-6_Pi_Stickers_A4.pdf` on A4 vinyl sticker paper at **100 % / actual size**. Check that the scale bar measures 50 mm, then cut along the dashed lines.

Contents: top lid (88×58 mm), 2 long-side strips (88×14), 2 end strips (58×14), port labels (POWER, HDMI0 AUDIO, HDMI1, USB MIDI, LINE OUT, L/R, PHONES, arrow tabs), section strip (LFO/DCO/VCF/VCA/ENV/CHORUS), CHORUS I/II strip, 3 small badges, 9 colour dots, and a 186×22 banner.

**Sizes are estimates.** KKSB doesn't publish outside dimensions for this case (KKSB product page, KKSB datasheet EAN 7350001161785, raspberrypi.dk). The sizes come from the Raspberry Pi 5 board (85×56 mm) plus wall and margin. Measure the flat areas first, because the side panels have vent slots. Port labels are separate tabs, so you can stick them next to each port on your own case.

Source: `make_stickers.py` (`pip install cairosvg`). Not affiliated with Roland.
