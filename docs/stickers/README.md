# JU-6 Pi stickers

Print `JU-6_Pi_Stickers_A4.pdf` on A4 vinyl sticker paper at **100 % / actual size**. Check that the scale bar measures 50 mm, then cut along the dashed lines.

Contents: top lid (88×58 mm), 2 long-side strips (88×12), 2 end strips (58×12), port labels, red section labels (LFO/DCO/HPF/VCF/VCA/ENV/CHORUS) and 3 badges (30×10).

Colours follow the Juno-106 panel: a cool charcoal-grey panel, white legends, a red "belt" line (the owner's manual calls it "the red belt"), red section graphics, and small blue and orange accents from the bank stripe and buttons.

**Sizes are estimates.** KKSB doesn't publish outside dimensions for this case. The sizes come from the Raspberry Pi 5 board (85×56 mm) plus wall and margin, so measure before cutting.

Source: `make_stickers.py` (`pip install cairosvg`). Not affiliated with Roland.
